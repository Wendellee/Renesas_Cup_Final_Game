针对你的光伏板上履带小车需求（无编码器、低速、可控），目标为**走直线**和**精确90°旋转**，以及**按键控制**，下面给出具体方案。

---

## 一、概念前提与约束
- 光伏板表面有一定坡度，但摩擦力相对均匀，没有大的颠簸。
- 车速极慢 → 惯性可忽略，利于开环控制和短时间位置估算。
- 没有轮子编码器 → 我们需要利用**时间 × PWM占空比**来近似行程，并结合其他传感器修正。

---

## 二、实现直线行走和90°旋转的策略

### 1. 走直线
在没有任何速度反馈的情况下，要让两个电机等速旋转，仅靠同样的PWM占空比很难抵消电机差异、负载不均和传动间隙。因此我们必须采用**反馈修正**。

#### 方案A：利用IMU的陀螺仪Z轴角速度做航向闭环
- 目标：保持角速度 \(\omega = 0\)。
- 方法：
  1. 读取IMU陀螺仪Z轴，得到实时角速度 \(\omega_z\)。
  2. 用PID控制器输出左右电机的PWM差分量。
  3. 基本算法：
     ```
     左PWM = base_PWM - PID(omega_z)
     右PWM = base_PWM + PID(omega_z)
     ```
  4. 这样一旦车身有微小偏转，系统立刻修正，使小车保持直线。

#### 方案B：利用光伏板的固有结构作为参照
- 如果光伏边框或电池片的接缝可以用于直线参考，可安装一排红外反射/光电传感器（例如两个间隔的前沿传感器），检测车头是否与接缝平行，通过微调左右电机实现对准。这是一种极低成本且鲁棒的直线保持方法。

如果没有IMU，方案B更适合；你已有IMU，则方案A是最直接的。

### 2. 精确90°旋转
需要进行**原地旋转**（即左右轮速度相反）。同样依赖陀螺仪的航向积分。

#### 步骤：
1. 设定目标角度增量 \(\Delta \theta = 90°\)（转为弧度）。
2. 清零陀螺仪航向角（积分起始）。
3. 以固定占空比使左轮正转、右轮反转（或相反），产生原地旋转角速度。
4. 实时读取陀螺仪Z轴角速度并积分（如用梯形积分），得到转过角度。
5. 当达到目标角度（例如89°时开始减速），停止电机并短时制动，等待稳定后再次读取航向，若仍有误差，重复小幅度修正旋转。
6. 由于车速很慢，可设置较低的角速度，避免超调。

#### 考虑陀螺漂移
在非常慢的转速下，陀螺仪零偏可能影响积分。每次旋转前可在静止时采样几秒取零偏均值，积分时减去零偏。

#### 无IMU的替代
若没有IMU，也可以利用**时间 + 固定的原地旋转角速度**来实现。通过实验测定在给定PWM下小车每秒转过的角度，然后用定时器控制转动的持续时间。但在不同电压或地面时误差较大，需多次测试并加入电压补偿。

## 三、位置估算（大致估计）
由于没有编码器，无法直接得到速度和位移，但可以基于**时间 × 标定速度**来估算。

### 标定方法：
1. 在平整地面（类似光伏板表面）上，固定电池电压（如满电）。
2. 给电机固定的PWM占空比 \(D\)，测量小车在 \(t\) 秒内直行的距离 \(L\)。
3. 反向计算线速度 \(v_{\text{cal}} = L/t\)。
4. 同理测试原地旋转角速度 \(\omega_{\text{cal}}\)（°/s）。
5. 记录多个电压点（如12.6V、12.0V、11.4V等），建立电压-速度映射表或拟合公式，在实际运行时用ADC检测电池电压，实时修正速度。

### 里程估算：
- 直行距离 = 当前电压下的标定线速 × 电机工作时间。
- 航向变化 = 当前电压下的标定角速 × 旋转持续时间（或者陀螺仪积分角度直接可得）。

这种方案在光伏板这类平坦且速度很慢的场景下，短距离（几米内）误差可以接受，足以支持清洁任务等。

## 四、按键控制逻辑（颗粒化与长按短按）

你提到的“把每一次按键的控制颗粒化”实际上就是**按键事件驱动**，而不是简单的轮询电平。一个好的状态机可以处理短按、长按、组合按等。

### 推荐按键扫描方法
- 设置一个定时器中断，周期 10–20 ms，在其中读取按键引脚电平。
- 实现去抖动和长按检测。

### 状态转移示例（单键控制）
假设仅用一个按键控制前进。可以定义：
- **短按**（按下 < 1秒）：向前走一小段固定距离（例如 10 cm）。
- **长按**（按下 ≥1秒）：持续向前走，直到按键松开。
- **松开**：停止。

伪代码：
```c
if (key_pressed) {
    press_time += TICK;  // 累加按下持续时间
    if (!action_running) {
        // 新按下，先短按等待计时
    }
} else {
    if (press_time > 0 && press_time < LONG_PRESS_THRESHOLD) {
        // 短按释放事件
        execute_short_press_action();  // 例如走10cm
    } else if (press_time >= LONG_PRESS_THRESHOLD && action_running) {
        // 长按释放事件
        stop_motion();
    }
    press_time = 0;
    action_running = 0;
}

// 在按键保持期间，长按启动
if (press_time == LONG_PRESS_THRESHOLD) {
    // 刚好到达长按阈值，启动连续动作
    action_running = 1;
    start_continuous_motion();
}
```

### 对于90°旋转
可分配另一个按键，或双击/组合键。例如：
- 短按左转键一次：小车向左精确旋转90°。
- 短按右转键一次：向右旋转90°。
- 长按则持续旋转直到松开。

### 颗粒化控制
“颗粒化”指将连续动作分解为原子动作。例如：
- “走10 cm”是一个原子任务。
- 调度器（RTOS或简单循环）每次只执行当前任务，任务完成前不响应新按键。
- 当按键触发，若当前无任务则插入一个任务；若任务正在进行，可以加入队列或忽略。

这样系统响应明确，不会出现多个动作叠加。

## 五、整合建议
基于上述，硬件配置建议：
- MPU6050/9250（陀螺仪+加速度计）用于角速度反馈，实现直线PID和90°旋转。
- 电池电压分压至ADC，用于速度补偿。
- 几个按键，通过GPIO读取。

整体控制流程：
1. 初始化，校准陀螺仪零偏。
2. 主循环不断读取按键，解析事件。
3. 根据事件创建任务（走直线、转90°、连续前进等）。
4. 在执行任务时，高频率（100Hz）运行PID控制，读取陀螺仪，调整两电机PWM。
5. 任务完成（如到时间或检测到里程）则停止，进入空闲等待按键。

这个方案没有编码器也能可靠运行，尤其适合速度很慢、短距离的光伏板清洁/巡检小车。
