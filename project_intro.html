01 — 项目概述

系统简介

本项目是一套由负压吸附履带巡检车和手持触控控制器组成的智能光伏板巡检系统。 巡检车通过负压风机吸附在倾斜的光伏板表面，使用 OV5640 摄像头采集图像， 并利用 Renesas RA8P1 双核 MCU 与 Ethos-U55 NPU 完成边缘端缺陷识别。

🛻

负压吸附巡检车

搭载 OV5640 摄像头、RGB 屏幕、履带驱动和负压风机，可以在倾斜光伏板表面稳定移动和吸附， 完成图像采集、AI 识别和结果显示。

🎮

手持触控控制器

基于 LVGL 9.5.0 构建 1024×600 图形界面，通过无线链路发送运动指令、 接收巡检画面、设备状态和 AI 检测结果。

🧠

边缘 AI 推理

利用 Cortex-M85 进行图像采集和预处理，Cortex-M33 负责实时运动控制， Ethos-U55 NPU 执行光伏板缺陷检测模型，实现视觉计算与实时控制的分离。

02 — 系统架构

双系统协作架构

高吞吐量的视觉任务与实时运动控制任务相互隔离，通过定义明确的 IPC 消息进行协作。

03 — 功能特性

核心能力

📷

图像采集与显示

OV5640 通过 MIPI-CSI 接入，SDRAM 帧缓冲，GLCDC 驱动 RGB LCD，已完成实机验证。

🤖

AI 缺陷识别

计划使用 Ethos-U55 NPU 执行光伏板缺陷检测模型，在边缘端完成推理与结果叠加。

🕹️

运动控制

GPT PWM 驱动履带和负压风机，MPU6050 航向闭环改善直线行驶与定角转向精度。

🛡️

安全保护

负压检测、电池电压、电机电流、通信心跳与失联保护，异常时进入安全状态。

📡

无线通信

NRF24L01+ 传输运动指令与状态，DA16200 Wi-Fi 传输压缩图像与检测结果。

🖥️

图形界面

LVGL 9.5.0 + GT911 触摸，1024×600 交互界面，支持远程操作与巡检画面显示。

07 — 代码仓库

仓库结构与功能分支

项目采用多分支协作开发，各功能分布在不同的 Git 分支中。

main

摄像头、MIPI-CSI、GLCDC、GPT 基础工程 — 当前默认分支。

car

MPU6050、航向闭环、履带和负压风机控制 — 巡检车固件基础。

gui

1024×600、LVGL 9.5.0、GT911、GUI Guider 界面 — 控制器固件基础。

color

800×480 彩条、SDRAM 和帧缓冲诊断 — 显示硬件调试。

FreeRTOS

FreeRTOS 11.1.0 单任务骨架 — RTOS 配置参考。
