# 瑞萨杯线下答辩材料

本目录用于 15 分钟线下答辩。核心演示是 `web/` 中的离线网页，不依赖网络、外部字体或在线脚本。

## 文件

- `web/index.html`：全屏答辩网页，共 11 个章节，包含独立的硬件三维模型展区。
- `start-report.cmd`：Windows 一键启动本地服务器并打开网页。
- `答辩讲稿.md`：逐页时间分配、主讲内容和过渡句。
- `现场检查清单.md`：设备、软件、演示流程与安全检查。
- `答辩数据依据.md`：网页中指标与架构结论的代码/文档来源。

## 启动

双击 `start-report.cmd`，默认打开：

```text
http://127.0.0.1:8124/
```

也可以在 `report/web` 目录运行：

```powershell
py -m http.server 8124 --bind 127.0.0.1
```

STL 模型由浏览器异步加载，因此不建议直接双击 `index.html` 使用 `file://` 打开。

## 控制

- 页面底部按钮：上一页、下一页。
- 顶部圆点：跳转章节。
- 顶部计时器：开始/暂停、归零。
- `F`：全屏。
- `O`：章节总览。
- 方向键、Page Up/Down、空格：翻页。
- 触摸屏：左右滑动翻页。

正式答辩前使用 1920×1080 或 1366×768 分辨率完整走一遍，并按 `现场检查清单.md` 完成离线与安全检查。
