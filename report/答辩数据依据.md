# 答辩数据依据

网页只把 `Vehicle` 与 `RemoteCtrl` 作为当前产品代码。`legacy-single-core` 仅用于历史图片和结构素材，不参与架构、功能或完成度判断。

| 网页结论 | 依据 |
|---|---|
| Vehicle 为 M85/M33 双核架构 | `Vehicle/README.md`、CPU0/CPU1 `configuration.xml` 与线程入口 |
| M85 1 GHz、M33 250 MHz、NPUCLK 500 MHz | CPU0/CPU1 `ra_gen/bsp_clock_cfg.h`：PLL1P 1 GHz，CPUCLK /1、CPUCLK1 /4、NPUCLK /2 |
| M85 六个任务、M33 五个任务 | `Vehicle/README.md` 的任务表及两个工程的 `*_thread_entry.c` |
| RemoteCtrl 四个任务 | `RemoteCtrl/README.md`、`doc/PROJECT_OVERVIEW.md` |
| 1024×600 RGB565 / LVGL 界面 | Vehicle Camera/Display 代码、RemoteCtrl Display Thread 与生成界面 |
| 200×112 Gray8 JPEG | Vehicle `encode_thread_entry.c`、RemoteCtrl 图像重组与 TJpgDec 路径 |
| JPEG 走共享 SDRAM 双槽 | Vehicle CPU0/CPU1 IPC 共享图像代码与 `Vehicle/README.md` |
| 导航走 32 位短 IPC | Vehicle `navigation_thread_entry.c`、`ipc_thread_entry.c` |
| 控制 8 B、信道 76、开启 ACK | 双方无线协议文档与 Radio 业务代码 |
| 视频 32 B、信道 100、NO_ACK 冗余 | `doc/NRF24_LINK_PROTOCOL.md`、`RemoteCtrl/doc/NRF24_VEHICLE_PROTOCOL.md` |
| 空中速率 2 Mbps、2 字节硬件 CRC | 双方 nRF24 初始化与协议文档 |
| 视频帧 250 ms 超时复位 | `RemoteCtrl/doc/NRF24_VEHICLE_PROTOCOL.md` 与 Video RX 状态机 |
| 导航 500 ms 失联停车 | Vehicle `vehicle_thread_entry.c` 与目标板交接记录 |
| Ethos-U55 YOLO 链路已集成 | Vehicle CPU0 AI 预处理、推理、后处理和快照代码 |
| 90% 车轮、80% 风机 | Vehicle IPC/Vehicle/Radio 代码及目标板交接记录 |
| ROI 65% / 80% 阈值 | Vehicle `navigation_thread_entry.c` 与自动巡检实施记录 |
| MPU6050 当前关闭 | `VEHICLE_MPU6050_ENABLE=0` 及目标板交接记录 |

## 不作为已完成指标的项目

- 稳定 FPS、连续帧号和长期丢帧率尚未量化。
- Ethos-U55 模型精度仍需赛题数据集验收。
- 真实负载下的吸附力、电流、温升和机械冲击尚未完成持续测试。
- MPU6050 因风机动力链引起 I2C 异常而暂时隔离。
- 当前 emergency stop 会同时停止车轮和吸附风机，尚未拆分“停车并保持吸附”和“全系统关闭”。
